# مدار · رياضيات الرابع الابتدائي

نموذج تفاعلي للفصل الثالث **الطرح** كاملاً (الكتاب ص ٤٦–٦١): الدروس الأربعة، والاختبار القبلي، ومراجعة الفصل، واختبار الفصل.

- غلاف الفصل ومسألة ناقلة النفط
- مختبر «إعادة التسمية» ولوحة أقراص متحركة، ومعلّم يشرح كل منزلة خطوة بخطوة
- الطالب يعيد التسمية بنفسه في كل تمرين طرح، مع تنبيه فوري عند الخطأ
- كل تمارين الفصل (١٠٥ تمارين) بتلميحات متدرجة
- شاشة نتيجة حسب أقسام الدرس

الصفحة كلها في ملف واحد: `index.html`.
