# مدار · رياضيات الرابع الابتدائي

نموذج تفاعلي للفصل الثالث **الطرح**، الدرس الأول **طرح الأعداد ضمن الملايين** (الكتاب ص ٤٦–٥٠):

- غلاف الفصل ومسألة ناقلة النفط
- ورقة شرح فيها جدول القيمة المكانية متحرك، يُظهر إعادة التسمية منزلة بمنزلة كما في الكتاب
- الاختبار القبلي وتمارين الدرس (أتأكد، أتحدث، أحل، أفكر، أكتب) بتلميحات متدرجة
- شاشة نتيجة حسب أقسام الدرس

الصفحة كلها في ملف واحد: `index.html`.
